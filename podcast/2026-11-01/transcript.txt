IASTRO: Autre thème du jour, et il concerne la sécurité.

VICTORIA: Trois alertes sont tombées le même jour. Elles rappellent que l'IA crée aussi de nouveaux risques. D'abord, des chercheurs de Parameter Labs décrivent une faille. Elle a permis de prendre le contrôle de comptes ChatGPT. Comment ? Via les mini-applications HTML interactives. Le mécanisme visait un cadre censé être isolé, qu'on appelle le sandbox. L'enjeu, c'est d'empêcher du code non fiable de s'échapper de cet espace. Ensuite, l'éditeur Cisco Talos révèle un logiciel malveillant. Il utilise une IA pour classer ses victimes selon leur valeur financière. Ce voleur de données s'appelle Volta. En clair, il hiérarchise les cibles selon leur intérêt financier. C'est une automatisation inquiétante du cybercrime. Enfin, selon The Decoder, OpenAI prévoit d'entraîner ses modèles sur certaines données de sessions jusqu'ici exclues. Ça soulève des questions sur le consentement. À partir du vingt-neuf novembre, ces données seraient utilisées, même quand l'entraînement a été désactivé. Après des critiques, un courriel aurait promis une option de retrait séparée. Pour un commerçant ou une PME, la règle est simple. Prudence avec les données sensibles confiées aux IA grand public.

IASTRO: Et on reste sur les agents avec un défi venu de Chine.

VICTORIA: Le laboratoire chinois DeepSeek a publié un prototype d'agent de codage plus autonome. C'est Bloomberg qui le rapporte. L'objectif est clair. Rivaliser avec Claude Code d'Anthropic, très populaire chez les développeurs. Et pourquoi c'est une étape ? Parce qu'un agent de codage ne se contente pas de suggérer des lignes de code. Le développeur Sridhar Ramaswamy rappelle une tendance de fond. Un niveau de performance d'IA donné deviendrait environ treize fois moins cher par an depuis quatre ans, selon Epoch. Mais il nuance. Produire plus de code ne crée pas automatiquement plus de valeur. Et les logiciels générés par IA arrivent avec un poison, les bugs catastrophiques. Pour une PME, l'essentiel tient en une phrase. Les outils de développement assistés par IA se démocratisent, mais la vérification reste cruciale.

IASTRO: Autre angle, maintenant, l'IA qui entre vraiment dans le travail.

Pour une PME, c'est un signal. L'IA s'installe dans des tâches métier concrètes, au-delà des simples chatbots.
